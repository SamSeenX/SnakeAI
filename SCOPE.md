# Project Scope: Retro Snake 198X

## In-Scope
* Single-player autonomous AI snake game loop
* Dynamic grid progression across five difficulty levels (16x16 up to 32x32)
* Local score and high-score persistence
* Responsive retro CRT canvas rendering and visual D-pad simulation
* Zero-dependency vanilla ES6 modular architecture (< 200 lines per file)
* PWA standalone manifest and offline asset readiness

## Backlog Ideas
* Hamiltonian cycle path fallback for guaranteed late-game grid clearance
* Manual override mode allowing human player keyboard and touch control
* Retro 8-bit sound effects using the Web Audio API synthesized oscillators
* Speed toggle settings (turbo mode vs classic pace)

## Out-of-Scope
* Heavy third-party JavaScript libraries or frameworks
* Online multiplayer networking or backend databases
* Complex 3D graphics or WebGL dependencies
